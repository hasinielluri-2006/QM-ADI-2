# RAG Analyst UI Upgrade

This package contains a polished React frontend concept for Querymind, an autonomous data intelligence platform.

## Included
- Premium dark AI workspace
- KPI result cards
- Interactive 2D charts
- Interactive 3D visualization using Plotly
- AI insight panel
- Collapsible SQL/details area
- Suggested follow-up questions
- Responsive sidebar + analysis workspace
- Framer Motion animations

## Run
1. Copy these files into your React/Vite project.
2. Install:
   npm install
   npm run dev

The UI uses mock result data until connected to your FastAPI endpoint.
